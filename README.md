Overview:

Evendi is a full-stack event management platform that allows users to create events, send invitations, track RSVPs, and manage event-related data in real time.
Tech Stack
Frontend: React.js, JavaScript, HTML, CSS
Backend: PHP
Database: MySQL
APIs: RESTful API integration

Features:
Event creation and management
RSVP tracking system
User authentication
Payment processing functionality
Real-time data updates

My Role:

Designed and managed MySQL database
Integrated frontend with backend services
Debugged and improved system performance


How to Run Locally:

Clone the repository
git clone https://github.com/SellyTlou/eventa
Move project to XAMPP htdocs
Import the database into MySQL
Start Apache and MySQL
Run the frontend using:
npm install  
npm start
